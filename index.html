Cluster

Data link: Bluetooth (MUTECH-BLE/2) to the cluster.
Yamaha CCU
The cluster connects to the bike's Y-Connect unit (CCU), logs in, keeps the link alive and passes every CCU message to this phone. Turn the key ON.

Phone ID

The 32-character ID your CCU already knows (from the Y-Connect pairing). It is sent once to the cluster and stored there. It is never part of the website.

Demo

Made-up engine values to try the screens. Marked "Demo data" on Engine and Bike.
Captures
Each recording is kept on this phone. Download gives the raw log, one CCU message per line: time, then the message in hexadecimal (the format the Mac decoder reads).
